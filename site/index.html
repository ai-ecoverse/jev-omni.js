jev-omni.js

A 12B decision classifier in the browser. A state, a question and its options in; one probability per option out, from a single forward pass on your GPU.

Jev-Omni is a Gemma 4 12B model with a 256-way decision head. @ai-ecoverse/jev-omni.js runs it on WebGPU through onnxruntime-web, for text and images.

Status

Work in progress, no live demo yet. Text and images work in Chrome on WebGPU and match the full-precision model. The browser bundle is 13.6 GB and needs about 16 GB of GPU memory, so it is for machines like a large-memory Apple Silicon Mac. The weights are not on Hugging Face yet; until they are, you build the bundle yourself (see the README). Video and audio are still to come.

API

import * as ort from "onnxruntime-web/webgpu";
import { loadJevOmni } from "@ai-ecoverse/jev-omni.js";

const jev = await loadJevOmni("/models/jev-omni", { ort });
const res = await jev.predict({
  state: "The meeting starts at 10 AM. It is now 9 AM.",
  question: "Has the meeting started?",
  options: ["Yes", "No"],
  // image: { width, height, data }   // optional RGBA pixels
});
res.prediction;      // the likeliest option
res.probabilities;   // { Yes: …, No: … }

2 to 256 options per question; quality is established up to 20. The loader checks every file's SHA-256 against the manifest.

How it works

  • Decoder: Jev-Omni's own bf16 weights, exported with a vendored draft of the onnxruntime-genai model builder that supports Gemma 4, as a hidden-state graph with int8 weights and fp32 activations. The 8 global-attention layers run in fp16 to fit Apple GPUs' workgroup memory.
  • Head: the last position's hidden state, normalized, through one linear layer to 256 logits, masked to the number of options.
  • Images: Gemma 4 has no separate vision tower. Images become 48 px patches through a small embedder (200 MB, fp32), ported to JS with pixel checks against Hugging Face's processor, and tokens of one image attend to each other in both directions.

Compared with kev.js and cua-s1.js

In decision-vision-bench, Jev-Omni ties Kev-4B vision on image questions, at 2.5× the download. It is clearly the strongest of the three on long text decisions (92.5% on the DecisionBench slice). For images in the browser, use kev.js; for long text decisions on a big machine, use this.
